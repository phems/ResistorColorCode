## Project Description
As a final assignment for the course Object Oriented Programming, we had to create a program that contains a Graphical User Interface (GUI). 
We chose to build a program that lets you choose the colors of a resistor and calculates its value. 
This project is significant for us as students majoring in Electrical Engineering, as it can save us so much time when building circuits. Hence, this is the project
we chose to build.

### Features 
- 4-Band Resistor Support – Allows users to select the 4-ring resistor configuration.
- 5-Band Resistor Support – Allows users to switch to the 5-ring resistor configuration.
- Interactive Color Selection – Provides dropdown menus where users can select resistor band colors.
- Visual Resistor Representation – Displays a resistor illustration with colored bands that correspond to the selected colors.
- Automatic Resistance Calculation – Displays the calculated resistance value based on the selected color bands.
- Tolerance Calculation – Displays the resistor's tolerance percentage.
